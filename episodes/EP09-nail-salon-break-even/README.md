## Windows预览与剪映导入

1. 下载交付的EP09 ZIP，右键“全部解压缩”。若单独下载MP4时浏览器直接播放，可按Ctrl+S保存。
2. 双击 `ep09-nail-salon.mp4`，用Windows媒体播放器查看，确认原声正常。
3. 打开CapCut电脑版/剪映专业版，新建项目→媒体/导入→选择MP4，拖到时间轴。
4. 画布选择9:16。成片已经烧录中英文字幕，不要再把SRT自动叠加一遍；SRT用于后续修改和参考。
5. 如需独立重做字幕，在源码调整WordCaptions或时间数据后重新渲染。普通用户直接描述修改点即可，不必安装编程工具。

本环境不能实际操作Windows/剪映GUI，不把通用MP4格式检查说成真实Windows导入实测。项目未使用AI配音，录音来自用户上传附件。

## 统一数据源与财务解释

`src/config.ts` 的input/model为所有画面数值的单一来源。金额用money统一格式化；派生金额不在场景中另写一套常量。

|指标|计算|结果|
|---|---|---:|
|月顾客|26×8|208|
|营业额 Revenue|208×60|$12,480|
|每位变动成本|材料、技师提成假设|$35|
|每位边际贡献|60−35|$25|
|月变动成本|208×35|$7,280|
|总边际贡献|208×25|$5,200|
|固定成本|假设|$5,000|
|经营利润 Operating Profit|5200−5000|$200|
|月保本顾客|5000÷25|200|
|日均保本顾客|200÷26|≈7.69|

200位/月对应零经营利润；每天固定8位、26天为208位/月，对应$200经营利润，**不是恰好零利润**。口播“接近八位”按近似理解，画面同时补出7.69与8位/天的区别。$200不是老板税后到手收入，不保证已包含老板合理工资。所有数值为假设，不是行业平均利润。

月度瀑布图用真实比例显示12480→5200→200；总贡献与最终利润为从零起的汇总柱，成本柱从前一余额悬浮扣减，固定成本5000不会错误地从零作收入柱。最终200柱很短是正确比例，另用大字突出，未夸大柱高。

## 口播和字幕同步

实际附件58.174667秒，成片向上取整到58.2秒；没有剪短、拉长或变速原声。开头原录音的约0.5秒自然留白保留，动画标题已出现。

28组双语字幕，中英文均44px、750weight；中文在上英文在下。图形区域严格裁剪在y<1248，字幕框y1320–1710，左右70px边距。长英文平衡拆成两行，同字号。此安全区用于减少遮挡，不保证所有设备不断变化的YouTube按钮位置。

中文基于本地SenseVoice CTC字符时间与用户稿件校正对齐；英文为自然翻译，按对应中文短句时间分配词高亮，**不是英语语音识别/音素对齐**。部分中文按正式稿修正，如“涉及”和材料/技师提成；音频本身不修改。中文参考字符匹配比例只代表文本匹配，不是时间准确率。尚未进行逐字人工听审，建议播放复核关键数字的入点。可以编辑timed.json和SRT；再次运行build_captions.py会覆盖手工时间修改。

场景时间：开场0–9.09；概念9.09–17.31；营业额17.31–25.71；成本反转25.71–38.49；保本38.49–48.87；结尾48.87–58.17。更细数字入点在config.timings中，来自真实录音而非平均分六段。

## 视觉、音频和许可

美甲店为原创分层SVG/CSS立体插画：柔和渐变、阴影、透视柜台、镜面、甲油瓶、独立刷笔和顾客手部、收银机；不是物理渲染的3D引擎，也不是整张静态图片推拉。贯穿的年轻女性店主在本仓库已有Owner组件上换装，具有开心/惊讶/平静表情，顾客独立活动。复用EP04/EP08的双语文字、卡片、缓动和字幕组件；没有覆盖原组件。

音乐由tools/make_music.py使用正弦谐波和通用和弦原创合成，gain0.17，预计约低于录音均值26dB；轻音效由tools/make_cues.py原创合成，gain0.32。无采样录音、第三方旋律、库存音乐、照片或未经授权素材。SFX对应0.55/2.4/6.95/21.99/29.55/35.97/42.57秒关键数字。设musicVolume=0并移除original-cues的Audio即可只保留原声。

沿用Remotion4.0.538、React19.3.1、TypeScript7.0.2、系统Chromium与Noto Sans CJK SC（SIL OFL字体，不分发源字体）。无新视频运行时依赖。Remotion适用单独Free/Company许可，见安装包LICENSE.md，不能把本项目package的ISC字段等同于Remotion授权。更早参考项目的许可审阅保留在EP08/REFERENCES.md；本期不复制外部模板或未确认可复用代码。

## 技术人员运行

```bash
cd episodes/EP09-nail-salon-break-even
npm --cache /workspace/.npm-cache ci
npm run typecheck
npm test
npm run studio
npm run render
```

Studio端口3094。渲染脚本会用现有FFmpeg规范视频色彩范围为通用yuv420p，并复制AAC音轨而不再次压缩。云环境脚本使用 `/usr/bin/chromium`，不是Windows本地路径。下载成片并剪辑不需要运行代码。

字幕/音乐生产工具使用已存在的/workspace/voice-tools，字体排版和截图工具使用/workspace/python-coffee-env；它们不是视频运行时依赖。替换public/narration.mp3后应重新测时长、生成CTC、校对script和timed，再调整timings/音效时点及音乐长度；不自动声称新音频已同步。

数学与字幕测试、TypeScript、实际全片解码、音轨预期混音对照、六场景关键帧显示结果均记入validation.json。没有逐字人工听审，也未在真实Windows环境操作播放器或剪映。

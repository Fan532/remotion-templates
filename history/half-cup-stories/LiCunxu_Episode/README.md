## Windows：下载与导入CapCut/剪映

1. 下载交付的LiCunxu_Episode.zip，右键→“全部解压缩”。无需安装编程工具。
2. 进入解压后的LiCunxu_Episode文件夹，里面有8个MP4及预览图。双击MP4，用Windows媒体播放器播放；本来就没有声音。
3. 打开CapCut电脑版或剪映专业版，点击“新建项目”→“媒体/导入”。按住Ctrl选择8个MP4后导入。
4. 将相应片段拖到你的旁白时间轴。素材建议顺序见上表；名称前无数字时请手动按上表排序。
5. 画布选16:9，另加自己的旁白和字幕。重要画面文字位于y850以上，底部y864–1080留给后期字幕；字幕过高仍可能遮挡，请在预览中确认。
6. 导出整条节目时选择1080p、30fps。

若浏览器直接播放单个MP4，Ctrl+S保存；文件扩展名应为.mp4而不是.html。本环境没有真实Windows/CapCut桌面，兼容性依据标准H.264/yuv420p文件检查，未实际点击验证导入。

## 源码修改与渲染

src/config.ts：统一颜色、片段列表/时长/旁白建议、地点文字与近似现代坐标。src/Film.tsx：八个场景及具体文字、时间点、SVG形状；修改叙事文字也需更新相应场景。不要只改年份而不改相关事件标题。地图禁止把近似城市点改标为已核实的古城址。

沿用本仓库Remotion4.0.538、React19.3.1、TypeScript7.0.2、Noto Serif CJK SC。当前云环境命令：npm ci；npm run typecheck；npm run studio（3093端口）；npm run render。render使用现有Chromium、FFmpeg和Python3依次渲染8段，并规范色彩范围。上述浏览器路径适用于Linux云环境，不是Windows复制粘贴教程。Windows用户直接下载成片剪辑即可。

布局包括：动态年份/人物剪影、三箭古籍卷轴、经纬参考地点图、事件时间轴、人物关系网、抽象宫城与左右对比。背景含独立粒子、纸张线纹与分层山形；无整张图片平移放大。所有SVG/CSS形状为本项目原创，复用前三段的色彩规范、帧动画方法和检查脚本。
